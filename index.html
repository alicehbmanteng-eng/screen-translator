🌐 中英双向 AI 翻译助手

截图由视觉 AI 直接识别和翻译；文本支持英文→中文、中文→英文。这个版本不再依赖浏览器里的基础 OCR 作为主要识图方式。
一、连接 AI 服务（首次设置）
不需要 Gemini API Key。请先在 Cloudflare Worker 中添加 Workers AI 绑定（变量名 AI）并设置 APP_ACCESS_TOKEN。完整步骤见下方部署说明。
请先在 LinkedIn、Facebook、Instagram 或其他 App 中截图，再在这里上传。文字很小时，建议先裁剪到需要的内容。单张图片最多 5 MB。
AI 会从截图中提取可见文字，填入“原文”和“译文”区域。
请特别检查客户姓名、公司名称、邮箱、网址、金额、数量、币种和交期。
如何接通 AI（无需 Gemini API Key）
1. 打开下方的 Cloudflare 控制台链接，创建一个 Worker。
2. 把仓库里的 cloudflare-worker.js 复制到 Worker 代码编辑器并部署。
3. 在 Worker 的设置里添加 Workers AI 绑定，变量名填写 AI。
4. 在“变量和机密”里添加 Secret：APP_ACCESS_TOKEN。用 Windows PowerShell 生成一个随机口令，部署后在本网页填入同一个口令。

说明
这个方案使用 Cloudflare Workers AI 的 Gemma 4 视觉模型。免费层有每日用量上限，性能和准确度需要用你的实际截图测试，不能承诺每次都达到 ChatGPT 或 Google Lens 的水平。网页不能自动读取其他 App 的屏幕，仍需先截图再上传。不要上传客户机密、密码或验证码。
