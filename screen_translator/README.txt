屏幕翻译助手 - 免费测试原型

使用方式：
1. 在 LinkedIn、Facebook、Instagram 或浏览器里截取屏幕。
2. 打开此网页，上传截图，选择英语或阿拉伯语。
3. 点击识别截图文字，再点击翻译成中文。

限制：这不是原生 iOS IPA，也不会自动读取其他 App 的屏幕。OCR 依赖外部 CDN；翻译使用公共演示接口，可能限流或不可用。请勿处理密码、验证码或敏感资料。

部署：把 index.html 上传到 GitHub 公开仓库，在 Settings > Pages 中选择 Deploy from a branch、main、/(root) 并保存。发布后用 iPhone Safari 打开 GitHub Pages 的 HTTPS 地址，点分享 > 添加到主屏幕。
